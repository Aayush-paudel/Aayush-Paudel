Put your own images here, e.g.:

- avatar.jpg   — your photo (referenced by PERSONAL_INFO.avatar in js/config.js)
- resume.pdf   — your CV (referenced by PERSONAL_INFO.resumeUrl)
- project screenshots, if you don't want to use external image URLs

Nothing in this folder is required for the site to run — the project
section currently uses hosted Unsplash placeholder images by default.
